# Customer Churn Prediction Platform

## What is this project about?

This project predicts **which bank customers are likely to leave the bank** using machine learning.

It takes customer details like **age, credit score, balance, activity, and number of products**, sends them to the ML model, and gives a **churn probability and risk level**.

### Basic Flow

Customer Data → ML Model → Churn Prediction → Risk Level

## Name Meaning

1. **Customer Churn** → Customers leaving the bank
2. **Prediction** → Predict who may leave
3. **Platform** → Complete full-stack application
